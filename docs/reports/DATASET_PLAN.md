# Canonical Dish Nutrition Dataset Plan

## Overview
**Target Size:** 300–800 canonical dishes  
**Focus:** Commonly consumed dishes in the United States  
**Data Sources:** USDA FoodData Central, OpenFoodFacts, curated averages  
**Coverage:** Home-style, restaurant-style, and fast-food variants

## 3. Variant Definition Rules

### When to Create Multiple Canonical Dishes

#### ✅ Create Separate Dish Entries When:

1. **Protein Type Differs**
   - Example: "Chicken burrito" vs "Beef burrito" vs "Bean burrito"
   - Rationale: Significant nutritional differences (protein, fat content)

2. **Cooking Method Changes Nutrition**
   - Example: "Fried chicken" vs "Grilled chicken" vs "Baked chicken"
   - Rationale: Oil absorption drastically changes calories and fat

3. **Portion Size Is Standard**
   - Example: "Small fries" vs "Medium fries" vs "Large fries"
   - Rationale: Fast food portions are well-defined, users search by size

4. **Sauce/Topping Significantly Alters Nutrition**
   - Example: "Plain pizza" vs "Pepperoni pizza" vs "Supreme pizza"
   - Rationale: Toppings add 30%+ calories

5. **Ingredient Mix Is Fundamentally Different**
   - Example: "Chicken Caesar salad" vs "Caesar salad (no protein)"
   - Rationale: Different primary ingredients

6. **Cultural/Regional Preparation Varies**
   - Example: "American-style fried rice" vs "Thai fried rice"
   - Rationale: Different base ingredients (soy sauce vs fish sauce)

#### ❌ Do NOT Create Separate Entries When:

1. **Only Garnish Differs**
   - Example: Don't separate "Tacos with cilantro" vs "Tacos without cilantro"
   - Solution: Use base recipe; cilantro is negligible

2. **Brand Name Only**
   - Example: Don't separate "McDonald's cheeseburger" vs "Burger King cheeseburger"
   - Solution: Create "Fast food cheeseburger" with averaged values

3. **Minor Seasoning Variations**
   - Example: Don't separate "Spicy chicken" vs "Mild chicken"
   - Solution: Use standard preparation

4. **Serving Style (Not Ingredients)**
   - Example: Don't separate "Dine-in burger" vs "To-go burger"
   - Solution: Same dish, different context

### Variant Text Strategy

Each canonical dish should have **5-15 textual variants** in `dish_variants` table:

**Example for "Chicken Tikka Masala":**
- Canonical: "Chicken Tikka Masala"
- Variants:
  - "chicken tikka masala"
  - "tikka masala"
  - "chicken tikka"
  - "indian butter chicken" (close enough)
  - "butter chicken" (technically different, but users conflate)
  - "chicken masala curry"
  - "tikka curry"
  - "creamy chicken curry"

**Variant Categories:**
1. **Exact match** (lowercase, normalized)
2. **Short forms** (abbreviations)
3. **Common misspellings** (if predictable)
4. **Synonyms** (regional terms)
5. **User language** ("I had tikka" instead of formal name)

## 4. Anti-Redundancy Guidelines

### Hierarchy of Specificity

**Level 1: Base Dish (Most General)**
- Example: "Fried chicken breast"
- Nutrition: Generic average from USDA

**Level 2: Style-Specific**
- Example: "Southern fried chicken breast" (buttermilk batter)
- Nutrition: More specific recipe

**Level 3: Brand-Specific (Fast Food Only)**
- Example: "KFC fried chicken breast"
- Nutrition: Published brand data

**Rule:** Include Level 1 for everything. Add Level 2 if preparation differs significantly. Add Level 3 only for top 10 fast food chains.

---

### Redundancy Checklist

Before adding a dish, ask:

1. **Is there already a dish with 80%+ same ingredients?**
   - If yes: Don't add. Instead, add as variant text.
   - Example: "Chicken wrap" is already covered by "Chicken burrito"

2. **Does this dish differ by <50 calories from existing?**
   - If yes: Check if protein source is the same
   - Example: "Grilled chicken sandwich" vs "Grilled chicken breast with bun" → Merge

3. **Is this a combination of two existing dishes?**
   - If yes: Don't add unless extremely common
   - Example: "Burger with fries" → Don't add (users can add both separately)

4. **Is this a minor modification?**
   - If yes: Use variant text, not new dish
   - Example: "No mayo burger" → Variant of "Cheeseburger"

---

### De-duplication Process

**Step 1: Normalize Names**
- Convert to lowercase
- Remove articles (the, a, an)
- Remove prepositions (with, without)
- Example: "A Burger with Cheese" → "burger cheese"

**Step 2: Ingredient Similarity**
- Extract main ingredients
- Compare using Jaccard similarity
- Threshold: >75% overlap → likely duplicate

**Step 3: Nutritional Proximity**
- Compare calories, protein, fat, carbs
- If all within 10% → likely duplicate

**Step 4: Manual Review**
- Review flagged duplicates
- Keep more common name
- Merge variant texts

## 5. Data Source Mapping

### Primary Sources

| Source | Use Case | Coverage | Access |
|--------|----------|----------|--------|
| **USDA FoodData Central** | Home-style dishes, raw ingredients | 500,000+ foods | API: fdc.nal.usda.gov |
| **Fast Food Nutrition Databases** | Chain restaurant data | Top 50 chains | Web scraping (public data) |
| **OpenFoodFacts** | Packaged foods, branded items | 2M+ products | API: world.openfoodfacts.org |
| **Restaurant Menus** | Sit-down restaurant averages | Major chains | Manual curation |

### Data Priority Rules

1. **Fast Food:** Use official brand nutrition data (99% accurate)
2. **Home-style:** Use USDA recipes or weighted averages
3. **Restaurant-style:** Use USDA + scaling for typical restaurant portions
4. **Ethnic Foods:** Use USDA ethnic foods database + regional cookbooks

## 6. Quality Control

### Validation Rules

**Nutrition Fact Checks:**
- Calories should approximately equal: `(protein_g × 4) + (carbs_g × 4) + (fat_g × 9)`
- Allow ±10% variance for rounding/fiber

**Reasonability Checks:**
- Protein should not exceed 50% of calories (except protein shakes)
- Fat should not exceed 70% of calories (except pure oils)
- Carbs typically 30-60% for mixed dishes

**Completeness:**
- All dishes must have: calories, protein, fat, carbs
- At least 70% should have: fiber, sugar, sodium
- Nice to have: vitamins, minerals

### Confidence Scoring

Assign confidence score based on data source:

| Confidence | Criteria | Example |
|------------|----------|---------|
| **1.0** | Official brand data from source | McDonald's Big Mac from McD website |
| **0.9** | USDA FoodData Central (SR Legacy) | "Chicken, broiler, breast, grilled" |
| **0.8** | USDA Branded Foods (verified) | Specific frozen dinner |
| **0.7** | OpenFoodFacts (multiple entries) | Average of 5+ similar products |
| **0.6** | Curated average from cookbooks | "Homemade lasagna" from 3 recipes |
| **0.5** | Estimated from components | "Restaurant pasta" from ingredient sum |

**Minimum Threshold:** 0.6 (don't include dishes with <0.6 confidence)
